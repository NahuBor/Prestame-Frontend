# Préstame - Plataforma Vecinal para la Economía Circular

**Préstame** es una plataforma web vecinal diseñada para fomentar la economía circular y la colaboración comunitaria. La aplicación permite a los usuarios publicar objetos que están dispuestos a prestar (como herramientas, utensilios o equipamiento) y conecta con otros vecinos que los necesitan de forma temporal, gestionando todo el ciclo del préstamo desde la solicitud hasta la devolución.
